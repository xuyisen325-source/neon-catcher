# 🌌 霓虹捕手 (Neon Catcher)

这是一个简单的网页 Canvas 小游戏。

### 📱 运行说明
本游戏专为触屏设计，请使用手机浏览器访问以获得完整体验：
👉 **[在线试玩地址](https://xuyisen325-source.github.io/neon-catcher/)**
（由于仅适配了触摸事件，在电脑上使用鼠标无法操作。）

### 🕹️ 游戏玩法
- **上半屏点击**：切换捕手颜色（青/粉）。
- **下半屏滑动**：左右移动捕手位置。
- **规则**：接住同色球得分，漏接同色球或碰到异色球扣血。

### 🛠️ 技术实现
- 使用原生 JavaScript 开发。
- 针对移动端触碰响应进行了处理，避免点击延迟。
- 支持本地最高分纪录保存。
